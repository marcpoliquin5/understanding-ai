# Glossary

Short definitions of terms used across Understanding AI, with a link to where each is explained in depth.

| Term | Definition | Read more |
|---|---|---|
| **Acquisition function** | In Bayesian optimization, a cheap score built from the surrogate's posterior mean and variance (expected improvement, UCB) whose maximizer is the next point to evaluate | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md#3-bayesian-optimization-deciding-where-to-look-established) |
| **Activation function** | Elementwise nonlinearity applied after a linear layer (ReLU, GELU, tanh) | [Backprop](docs/02-deep-learning/neural-networks-and-backprop.md#activation-functions) |
| **Adam / AdamW** | Adaptive optimizers that scale each parameter's step by running gradient statistics; AdamW decouples weight decay | [Optimization](docs/00-foundations/optimization.md#momentum-and-adaptive-methods) |
| **Agent** | A system that repeatedly observes, decides, and acts toward a goal, often an LLM with tools | [Agents](docs/03-modern-ai/retrieval-tools-and-agents.md) |
| **Analog in-memory computing** | Computing a matrix-vector product inside the memory array that stores the weights, using circuit physics instead of moving weights to a processor | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#2-the-crossbar-ohm-multiplies-kirchhoff-adds-established) |
| **Attention** | Weighted averaging of value vectors, with weights from query–key similarity | [Transformers](docs/02-deep-learning/transformers.md) |
| **Backpropagation** | Reverse-mode application of the chain rule to compute all gradients efficiently | [Backprop](docs/02-deep-learning/neural-networks-and-backprop.md#backpropagation) |
| **Barren plateau** | Exponentially vanishing gradients in large random quantum circuits | [Quantum ML](docs/06-frontiers/quantum-machine-learning.md) |
| **Bayesian optimization** | Sample-efficient optimization of an expensive black-box function by repeatedly fitting a probabilistic surrogate, usually a Gaussian process, and evaluating where an acquisition function is highest | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md) |
| **Bellman equation** | Recursive relation defining the value of a state through the value of successor states | [RL](docs/01-classical-ml/reinforcement-learning.md) |
| **Benchmark contamination** | Test items, or close copies, appearing in a model's training data, so a score partly measures memory | [Evaluation](docs/03-modern-ai/evaluation-and-benchmarks.md#31-contamination-established) |
| **Bradley–Terry model** | Model of pairwise preferences in which $P(A \succ B) = \sigma(r_A - r_B)$ for latent scores $r$; the standard loss for training reward models | [Reward models](docs/05-alignment-safety-interpretability/reward-model-failure-modes.md#1-what-a-reward-model-is-established) |
| **Capacity factor** | In a mixture-of-experts layer, the multiple of the even-split token count that each expert can accept per batch; tokens beyond it are dropped or rerouted | [Mixture of experts](docs/02-deep-learning/mixture-of-experts.md#3-the-central-problem-keeping-the-experts-busy-established) |
| **Chain of thought** | Prompting or training a model to write intermediate reasoning steps | [LLMs](docs/03-modern-ai/large-language-models.md#prompting-for-reasoning) |
| **Conductance drift** | Slow change of a programmed device conductance after writing; in phase-change memory roughly a power law $G(t) \propto t^{-\nu}$ | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#4-why-the-answer-is-always-a-little-wrong-established) |
| **Coverage (repeated sampling)** | Fraction of problems solved by at least one of $k$ sampled attempts; it grows with $k$ and becomes accuracy only when a verifier can pick the right attempt | [Code generation](docs/03-modern-ai/code-generation-and-program-synthesis.md#4-sample-filter-select-established) |
| **Cross-entropy** | Expected negative log-probability a model assigns to the true outcomes; the standard classification and language-model loss | [Probability](docs/00-foundations/probability-and-information.md) |
| **Crossbar array** | Grid of row and column wires with a programmable device at each crossing; applying row voltages yields column currents equal to a matrix-vector product | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#2-the-crossbar-ohm-multiplies-kirchhoff-adds-established) |
| **Delta rule (fast weights)** | Memory write that stores only the correction $\beta(\mathbf{v} - W\mathbf{k})\mathbf{k}^\top$, one online gradient step on a key-to-value regression; the basis of DeltaNet | [Fast-weight programmers](docs/06-frontiers/fast-weight-programmers.md#3-the-delta-rule-memory-that-can-correct-itself-established) |
| **Dictionary learning** | Learning an overcomplete set of directions so that each input is a sparse combination of a few of them | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md#2-dictionary-learning-the-old-idea-established) |
| **Diffusion model** | Generative model that learns to reverse a gradual noising process | [Generative](docs/03-modern-ai/generative-models.md#diffusion-models) |
| **Double descent** | Test error falling, rising, then falling again as capacity grows past the interpolation threshold | [Learning theory](docs/00-foundations/learning-theory.md#double-descent) |
| **DPO** | Direct preference optimization: fit preferences with a classification-style loss instead of RL | [LLMs](docs/03-modern-ai/large-language-models.md#direct-preference-optimization-dpo) |
| **Dynamical isometry** | Initialization under which all singular values of a deep network's input–output Jacobian are near one, so signals survive depth | [Normalization and μP](docs/02-deep-learning/normalization-initialization-mup.md#1-initialization-keeping-the-forward-pass-alive-established) |
| **Edge of chaos** | Boundary between ordered and chaotic dynamics where deep signal propagation is possible | [Dynamics](docs/06-frontiers/nonlinearity-and-dynamical-systems.md) |
| **Edge of stability** | Regime where the loss curvature hovers near $2/\eta$ during gradient descent | [Optimization](docs/00-foundations/optimization.md#second-order-ideas) |
| **Embedding** | A learned vector representing a token, image patch, or other item | [Linear algebra](docs/00-foundations/linear-algebra.md) |
| **Empirical Fisher** | Average outer product of per-example gradients at the observed labels; cheap, but generally not the Fisher and not a curvature estimate | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#3-the-empirical-fisher-trap-established) |
| **Empirical spectral density (ESD)** | Histogram of the eigenvalues of a layer's weight correlation matrix $W^\top W/N$ | [Heavy-tailed spectra](docs/06-frontiers/heavy-tailed-weight-spectra.md#1-the-random-baseline-marchenkopastur-established) |
| **Energy per MAC** | Energy spent per multiply-accumulate; for optical hardware it may count only detected light, laser power, or the whole system, which differ by orders of magnitude | [Optical energy](docs/06-frontiers/optical-energy-and-nonlinearity.md) |
| **Expected improvement (EI)** | Acquisition function equal to the expected amount by which a point beats the best value so far; balances high mean against high uncertainty in closed form | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md#3-bayesian-optimization-deciding-where-to-look-established) |
| **Fast weights** | A weight matrix rewritten during a forward pass, usually by outer products programmed by a slower trained network; causal linear attention is an example | [Fast-weight programmers](docs/06-frontiers/fast-weight-programmers.md#1-slow-weights-that-program-fast-weights-established) |
| **Feature absorption** | An SAE failure where a general feature silently stops firing on cases that a more specific feature has taken over, driven by the sparsity objective | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md#7-the-reckoning-what-saes-do-not-give-you-active-research) |
| **Fill-in-the-middle (FIM)** | Training transformation that moves a middle span of a document to its end so a left-to-right model learns to complete code given what comes before and after the cursor | [Code generation](docs/03-modern-ai/code-generation-and-program-synthesis.md#3-code-as-language-established) |
| **Fisher information matrix** | Expected outer product of the score $\nabla_\theta \log p_\theta$; the second-order expansion of KL divergence and the metric of information geometry | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#1-models-as-points-on-a-curved-space-established) |
| **FlashAttention** | An exact attention kernel that tiles the computation to stay in fast on-chip memory and, in the backward pass, rebuilds the attention matrix from the saved per-row log-sum-exp instead of storing it | [Attention gradients](docs/02-deep-learning/attention-gradients.md#5-the-identity-that-made-flashattention-possible-established) |
| **Fokker–Planck equation** | Partial differential equation for how the probability density of a diffusion evolves over time; used to study where SGD's parameters spend their time | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md#1-from-a-noisy-update-to-a-diffusion-established) |
| **Foundation model** | Large model pretrained on broad data and adapted to many tasks | [Modern AI](docs/03-modern-ai/README.md) |
| **Fractal dimension** | Non-integer measure of how detail scales with resolution | [Fractals](docs/06-frontiers/fractal-and-self-similar-structure.md) |
| **Gaussian process (GP)** | A distribution over functions in which any finite set of values is jointly Gaussian, defined by a mean and a kernel; gives closed-form predictions with error bars | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md#1-a-distribution-over-functions-established) |
| **Gradient noise scale** | Ratio of the gradient-noise variance to the squared gradient norm; predicts the largest batch size that still speeds up training | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md#6-scaling-rules-for-adaptive-optimizers-and-modern-pre-training-active-research) |
| **Grokking** | Delayed, abrupt generalization long after the training set is memorized | [Learning theory](docs/00-foundations/learning-theory.md#grokking) |
| **Hallucination** | Fluent output not supported by inputs or facts | [LLMs](docs/03-modern-ai/large-language-models.md#known-failure-modes) |
| **Hardware-aware training** | Training a network in software with the noise and quantization of the target analog hardware injected, so it stays accurate when deployed on that hardware | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#5-making-networks-survive-the-analog-path-established) |
| **Heavy-Tailed Self-Regularization (HT-SR)** | The observation and theory that well-trained layers have power-law-tailed eigenvalue spectra whose exponent tracks model quality | [Heavy-tailed spectra](docs/06-frontiers/heavy-tailed-weight-spectra.md) |
| **Implicit gradient regularization** | The hidden penalty on gradient norm that finite gradient-descent steps add to the loss, found by backward error analysis | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md#5-implicit-bias-what-sgd-minimizes-besides-the-loss-active-research) |
| **In-context learning** | Performing a new task from examples in the prompt without weight updates | [LLMs](docs/03-modern-ai/large-language-models.md#in-context-learning) |
| **Induction head** | Attention circuit that completes repeated patterns (`A B … A → B`) | [Interpretability](docs/05-alignment-safety-interpretability/interpretability.md) |
| **Intermediate representation (IR)** | A compiler's internal description of a program; ML compilers lower from tensor-level to loop-level IRs | [ML compilers](docs/04-systems/ml-compilers.md#the-anatomy-of-an-ml-compiler) |
| **IR drop** | Voltage lost along the resistance of crossbar wires, so devices far from the drivers see less voltage than intended | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#4-why-the-answer-is-always-a-little-wrong-established) |
| **K-FAC** | Kronecker-factored approximate curvature: approximates each layer's Fisher block as a Kronecker product of activation and gradient covariances | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#4-making-it-affordable-k-fac-shampoo-and-soap-established-active-research) |
| **KL divergence** | Asymmetric measure of how one distribution differs from another | [Probability](docs/00-foundations/probability-and-information.md) |
| **KV cache** | Stored keys and values of past tokens reused during generation | [Inference](docs/04-systems/inference-and-efficiency.md) |
| **Linear scaling rule** | Multiply the learning rate by $k$ when the batch size grows by $k$, keeping SGD's noise temperature fixed; holds up to a problem-dependent batch size | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md#2-temperature-and-why-ηb-is-the-knob-established) |
| **LLM-as-a-judge** | Using a strong language model to grade or compare other models' open-ended answers; fast but prone to position and verbosity biases | [Evaluation](docs/03-modern-ai/evaluation-and-benchmarks.md#35-judges-have-biases-established) |
| **Load balancing (MoE)** | Keeping tokens spread evenly over experts, by an auxiliary loss, capacity limits, expert-choice routing, or a selection-only bias | [Mixture of experts](docs/02-deep-learning/mixture-of-experts.md#3-the-central-problem-keeping-the-experts-busy-established) |
| **Log-sum-exp** | $\log \sum_j e^{s_j}$, the softmax normalizer in log space; saving one per attention row is enough to rebuild the softmax exactly in the backward pass | [Attention gradients](docs/02-deep-learning/attention-gradients.md#5-the-identity-that-made-flashattention-possible-established) |
| **LoRA** | Fine-tuning by learning a low-rank update to frozen weights | [LLMs](docs/03-modern-ai/large-language-models.md#efficient-adaptation) |
| **Mach–Zehnder interferometer (MZI)** | Programmable 2×2 optical element; meshes of MZIs implement matrices in photonic chips | [Photonics](docs/06-frontiers/photonic-computing.md) |
| **Marchenko–Pastur law** | Limiting eigenvalue distribution of a large random matrix's correlation matrix, with bounded support; the null model for weight spectra | [Heavy-tailed spectra](docs/06-frontiers/heavy-tailed-weight-spectra.md#1-the-random-baseline-marchenkopastur-established) |
| **Maximal Update Parametrization (μP)** | Per-layer scaling of initialization and learning rates with width so features keep learning at every size and hyperparameters transfer from small to large models | [Normalization and μP](docs/02-deep-learning/normalization-initialization-mup.md#3-μp-making-hyperparameters-survive-scale-established-with-active-refinements) |
| **Memristor** | Two-terminal device whose resistance depends on its history and is retained; proposed by Chua in 1971 and now used loosely for resistive memory devices | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#3-the-devices-established) |
| **Mixture of experts (MoE)** | Layer that routes each token to a few of many expert sub-networks, decoupling parameter count from compute per token | [Mixture of experts](docs/02-deep-learning/mixture-of-experts.md) · [Inference](docs/04-systems/inference-and-efficiency.md#mixture-of-experts) |
| **Model collapse** | Degradation from training recursively on model-generated data | [Recursion](docs/06-frontiers/recursion-and-self-improvement.md#model-collapse) |
| **Muon** | Optimizer that replaces each hidden-layer momentum matrix by its nearest orthogonal matrix $UV^\top$, computed with a Newton–Schulz iteration | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#5-a-different-ruler-muon-and-steepest-descent-in-the-spectral-norm-active-research) |
| **Natural gradient** | Gradient preconditioned by the inverse Fisher, $F^{-1}\nabla L$: steepest descent when step size is measured by KL divergence between predictions | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#2-the-natural-gradient-established) |
| **Neural ODE** | Network whose hidden state evolves by a learned differential equation | [Dynamics](docs/06-frontiers/nonlinearity-and-dynamical-systems.md) |
| **NISQ** | Noisy intermediate-scale quantum: today's uncorrected quantum devices | [Quantum ML](docs/06-frontiers/quantum-machine-learning.md) |
| **Online softmax** | Computing a softmax in one streaming pass by keeping a running maximum and rescaling a running sum as new scores arrive | [Attention gradients](docs/02-deep-learning/attention-gradients.md#5-the-identity-that-made-flashattention-possible-established) |
| **Operator fusion** | Merging several operations into one kernel so intermediates stay in fast memory instead of off-chip memory | [ML compilers](docs/04-systems/ml-compilers.md#fusion-quantified) |
| **pass@k** | Probability that at least one of $k$ sampled solutions passes the tests, estimated without bias from $n \ge k$ samples | [Evaluation](docs/03-modern-ai/evaluation-and-benchmarks.md#passk) |
| **Perplexity** | Exponentiated per-token cross-entropy; effective branching factor of a language model | [Probability](docs/00-foundations/probability-and-information.md) |
| **Pre-LN / Post-LN** | Placing layer normalization inside each residual branch (Pre-LN) or after the residual addition (Post-LN) in a transformer | [Normalization and μP](docs/02-deep-learning/normalization-initialization-mup.md#where-the-norm-goes-matters) |
| **Program synthesis** | Automatically constructing a program that meets a specification, given as a logical formula, input-output examples, a partial program, or natural language | [Code generation](docs/03-modern-ai/code-generation-and-program-synthesis.md#1-synthesis-before-language-models-established) |
| **Programming by example** | Program synthesis from input-output examples, typically by searching a small domain-specific language; the approach behind Flash Fill | [Code generation](docs/03-modern-ai/code-generation-and-program-synthesis.md#1-synthesis-before-language-models-established) |
| **QK-norm** | Normalizing queries and keys (usually with LayerNorm) before their dot product, so attention logits cannot grow without bound and saturate the softmax | [Attention gradients](docs/02-deep-learning/attention-gradients.md) |
| **Quantization** | Representing weights or activations with fewer bits | [Inference](docs/04-systems/inference-and-efficiency.md#quantization) |
| **RAG** | Retrieval-augmented generation: retrieve documents and condition the answer on them | [Agents](docs/03-modern-ai/retrieval-tools-and-agents.md) |
| **Reservoir computing** | Using a fixed nonlinear dynamical system plus a trained linear readout | [Dynamics](docs/06-frontiers/nonlinearity-and-dynamical-systems.md) |
| **Residual connection** | Skip path that adds a block's input to its output | [Architectures](docs/02-deep-learning/architectures.md#residual-networks) |
| **Reward hacking** | A policy raising a proxy reward by exploiting its flaws rather than doing the intended task; also called specification gaming | [Reward models](docs/05-alignment-safety-interpretability/reward-model-failure-modes.md#4-a-field-guide-to-failure-modes-established-and-active-research) |
| **Reward model** | A learned scorer, usually trained on human preference comparisons, that stands in for human judgement during RLHF or best-of-$n$ sampling | [Reward models](docs/05-alignment-safety-interpretability/reward-model-failure-modes.md) |
| **Reward over-optimization** | The rise-then-fall of true quality as a policy is optimized further against a learned reward; Goodhart's law measured | [Reward models](docs/05-alignment-safety-interpretability/reward-model-failure-modes.md#3-the-shape-of-over-optimization-established) |
| **RLHF** | Reinforcement learning from human feedback via a learned reward model | [LLMs](docs/03-modern-ai/large-language-models.md) |
| **Router (gating network)** | The small learned layer that scores experts for each token and selects the top $k$ in a mixture-of-experts model | [Mixture of experts](docs/02-deep-learning/mixture-of-experts.md#2-the-layer-precisely-established) |
| **Scaling law** | Power-law relation between loss and parameters, data, or compute | [Scaling laws](docs/02-deep-learning/scaling-laws.md) |
| **Self-referential weight matrix (SRWM)** | A weight matrix that generates its own keys, values and learning rates and updates itself with them at runtime | [Fast-weight programmers](docs/06-frontiers/fast-weight-programmers.md#6-networks-that-rewrite-themselves-active-research) |
| **Self-supervised learning** | Learning from targets constructed from the data itself | [Unsupervised](docs/01-classical-ml/unsupervised-learning.md) |
| **Shot noise** | Fluctuation in photon counts; with $n$ detected photons the signal-to-noise ratio is $\sqrt{n}$, which sets the optical energy floor for analog optical computing | [Optical energy](docs/06-frontiers/optical-energy-and-nonlinearity.md#4-the-physical-floor-shot-noise-established) |
| **Sparse autoencoder (SAE)** | A wide autoencoder trained to reconstruct a network's activations from a few active latents, used to find interpretable feature directions | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md) |
| **Spiking neural network** | Network of neurons that communicate with discrete spikes in time | [Neuromorphic](docs/06-frontiers/neuromorphic-computing.md) |
| **Standard quantum limit (optical neural networks)** | Minimum optical energy per MAC set by photodetector shot noise; can fall below one photon per MAC for wide matrices | [Optical energy](docs/06-frontiers/optical-energy-and-nonlinearity.md#4-the-physical-floor-shot-noise-established) |
| **Stochastic differential equation (SDE)** | A differential equation with a random noise term; with small learning rates SGD is approximately one, with temperature set by learning rate over batch size | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md) |
| **Stochastic gradient Langevin dynamics (SGLD)** | Minibatch gradient steps plus injected Gaussian noise and a decaying step size, so the iterates sample a Bayesian posterior instead of converging | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md#8-noise-on-purpose-langevin-sampling-established) |
| **Superposition** | Representing more features than dimensions using nearly orthogonal directions | [Interpretability](docs/05-alignment-safety-interpretability/interpretability.md#superposition-and-sparse-features) |
| **SVD** | Factorization $W = U\Sigma V^\top$ into rotations and scalings | [Linear algebra](docs/00-foundations/linear-algebra.md) |
| **Sycophancy** | A model telling users what they appear to want to hear rather than what is true, partly driven by human preference data | [Reward models](docs/05-alignment-safety-interpretability/reward-model-failure-modes.md#4-a-field-guide-to-failure-modes-established-and-active-research) |
| **Token** | Unit of text (often a sub-word) processed by a language model | [Transformers](docs/02-deep-learning/transformers.md) |
| **TopK SAE** | A sparse autoencoder that keeps only the $k$ largest latent activations per input, fixing sparsity directly instead of penalizing it | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md#4-the-sparsity-penalty-and-why-it-kept-changing-established) |
| **Transcoder** | A wide, sparse layer trained to predict an MLP's output from its input, so the MLP can be replaced by readable features for circuit analysis | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md#5-from-features-to-circuits-active-research) |
| **Transformer** | Architecture built from attention and MLP blocks with residual connections | [Transformers](docs/02-deep-learning/transformers.md) |
| **Triton** | A language and compiler for writing GPU kernels in terms of tiles of data | [ML compilers](docs/04-systems/ml-compilers.md#triton-tiles-as-the-unit-of-thought) |
| **World model** | Learned model of environment dynamics used for prediction and planning | [World models](docs/06-frontiers/world-models.md) |
