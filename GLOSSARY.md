# Glossary

Short definitions of terms used across Understanding AI, with a link to where each is explained in depth.

| Term | Definition | Read more |
|---|---|---|
| **Absorbing state** | In discrete diffusion, a special `[MASK]` token that corrupted positions jump to and never leave; the corruption used by masked diffusion language models | [Diffusion LMs](docs/03-modern-ai/diffusion-language-models.md#2-diffusion-on-discrete-tokens-established) |
| **Acquisition function** | In Bayesian optimization, a cheap score built from the surrogate's posterior mean and variance (expected improvement, UCB) whose maximizer is the next point to evaluate | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md#3-bayesian-optimization-deciding-where-to-look-established) |
| **Action transaction** | In Secure-CUA, a small per-step program a computer-use agent commits to before reading untrusted screen content, fixing which questions it may ask of that content and how the answers may be used | [Multimodal prompt injection](docs/05-alignment-safety-interpretability/multimodal-prompt-injection-computer-use-agents.md#42-deciding-before-looking-masking-and-action-transactions) |
| **Action-conditioned world model** | A generative model that predicts future observations given past observations *and* a sequence of actions, so an agent can plan or be tested inside it | [Video world models](docs/06-frontiers/evaluating-video-world-models-closed-loop.md#1-two-kinds-of-evaluation-established) |
| **Activation function** | Elementwise nonlinearity applied after a linear layer (ReLU, GELU, tanh) | [Backprop](docs/02-deep-learning/neural-networks-and-backprop.md#activation-functions) |
| **Adam / AdamW** | Adaptive optimizers that scale each parameter's step by running gradient statistics; AdamW decouples weight decay | [Optimization](docs/00-foundations/optimization.md#momentum-and-adaptive-methods) |
| **Adaptive attack (prompt injection)** | An attack tuned against a specific defense, by gradient search, reinforcement learning, random search or human red-teaming; most defenses that report near-zero success against static attacks fall to one | [Prompt injection](docs/05-alignment-safety-interpretability/prompt-injection-and-tool-use-security.md#6-benchmarks-and-the-adaptive-attack-problem-established-active-research) |
| **Agent** | A system that repeatedly observes, decides, and acts toward a goal, often an LLM with tools | [Agents](docs/03-modern-ai/retrieval-tools-and-agents.md) |
| **AI control** | Designing deployments of a possibly misaligned model so that it cannot cause unacceptable outcomes even if it tries, and testing them against a red team that plays the model adversarially | [AI control](docs/05-alignment-safety-interpretability/ai-control-protocols.md#1-control-versus-alignment-established) |
| **Analog in-memory computing** | Computing a matrix-vector product inside the memory array that stores the weights, using circuit physics instead of moving weights to a processor | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#2-the-crossbar-ohm-multiplies-kirchhoff-adds-established) |
| **Any-order autoregressive model** | A model trained to predict tokens in every possible generation order rather than only left to right; masked diffusion is equivalent to one | [Diffusion LMs](docs/03-modern-ai/diffusion-language-models.md#3-masked-diffusion-is-a-weighted-masked-language-model-established) |
| **Arithmetic coding** | Lossless code that turns any next-symbol model into a compressor whose output length is within about two bits of the model's total negative log-probability | [Information theory](docs/00-foundations/information-theory-for-ml.md#2-prediction-is-compression-established) |
| **Attack selection** | An attacker's choice of when to attack (and when to abort), picking opportunities a monitor is least likely to flag; it lowers measured safety without improving the attack itself | [AI control](docs/05-alignment-safety-interpretability/ai-control-protocols.md#5-the-red-team-keeps-getting-stronger-active-research) |
| **Attention** | Weighted averaging of value vectors, with weights from query–key similarity | [Transformers](docs/02-deep-learning/transformers.md) |
| **Attention dilution** | The tendency of kernel-based linear attention to spread its weights nearly evenly over a long context instead of concentrating on the relevant tokens | [Linear attention](docs/02-deep-learning/linear-attention.md#4-choosing-the-kernel-instead-of-approximating-it-established-active-research) |
| **Attention sink** | Initial tokens that receive large attention weight regardless of content; keeping them lets a windowed KV cache stay stable on long streams | [KV cache](docs/04-systems/kv-cache.md#4-keeping-fewer-tokens-eviction-and-selection-active-research) |
| **Backpropagation** | Reverse-mode application of the chain rule to compute all gradients efficiently | [Backprop](docs/02-deep-learning/neural-networks-and-backprop.md#backpropagation) |
| **Barren plateau** | Exponentially vanishing gradients in large random quantum circuits | [Quantum ML](docs/06-frontiers/quantum-machine-learning.md) |
| **Bayesian optimization** | Sample-efficient optimization of an expensive black-box function by repeatedly fitting a probabilistic surrogate, usually a Gaussian process, and evaluating where an acquisition function is highest | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md) |
| **Bellman equation** | Recursive relation defining the value of a state through the value of successor states | [RL](docs/01-classical-ml/reinforcement-learning.md) |
| **Best-of-N** | Ranking *N* sampled completions with a verifier or reward model and returning the top one; quality rises with *N* only while the verifier stays reliable | [Prefix-aware multi-sample serving](docs/04-systems/prefix-aware-multi-sample-serving.md) · [Reasoning models](docs/03-modern-ai/reasoning-models-and-test-time-compute.md) |
| **Benchmark contamination** | Test items, or close copies, appearing in a model's training data, so a score partly measures memory | [Evaluation](docs/03-modern-ai/evaluation-and-benchmarks.md#31-contamination-established) |
| **BF16 (bfloat16)** | A 16-bit float with FP32's 8 exponent bits and 7 mantissa bits: the same range as FP32 at lower resolution, the default format for training compute | [Low-precision training](docs/04-systems/low-precision-training.md#1-where-the-bits-go-established) |
| **Bits per byte** | Compressed length of a text under a model divided by its raw length in bytes; a tokenizer-independent way to compare language models | [Information theory](docs/00-foundations/information-theory-for-ml.md#2-prediction-is-compression-established) |
| **Block diffusion** | Generating text block by block from left to right, with diffusion-style parallel unmasking inside each block; allows variable length and KV caching | [Diffusion LMs](docs/03-modern-ai/diffusion-language-models.md#4-generating-text-by-un-masking-established) |
| **Bond dimension** | In a tensor network, the size of an index joining two cores; it bounds the rank, and so the correlation or entanglement, that can pass across that cut | [Tensor networks](docs/06-frontiers/tensor-networks-as-ml-models.md#2-the-tensor-train-or-matrix-product-state-established) |
| **Born machine** | Generative model that assigns each configuration a probability equal to the normalized squared amplitude of a tensor network or quantum state; MPS versions give exact likelihoods and perfect samples | [Tensor networks](docs/06-frontiers/tensor-networks-as-ml-models.md#42-born-machines-and-probabilistic-models-active-research) |
| **Bradley–Terry model** | Model of pairwise preferences in which $P(A \succ B) = \sigma(r_A - r_B)$ for latent scores $r$; the standard loss for training reward models | [Reward models](docs/05-alignment-safety-interpretability/reward-model-failure-modes.md#1-what-a-reward-model-is-established) |
| **Branched rollout** | Short model rollout started from a real state in the replay buffer rather than from the initial state, so model errors cannot compound far (MBPO) | [Model-based RL](docs/06-frontiers/model-based-rl-compounding-error.md#3-use-the-model-only-as-far-as-you-trust-it-established) |
| **Budget forcing** | Controlling how long a reasoning model thinks by cutting its reasoning off at a token limit or appending "Wait" when it tries to stop early | [Reasoning models](docs/03-modern-ai/reasoning-models-and-test-time-compute.md#5-spending-compute-at-test-time-established) |
| **Call–performance threshold (CPT)** | Smallest fraction of strong-model calls a router needs to recover a given share of the weak-to-strong quality gap (e.g. CPT(50%)) | [Inference-time routing](docs/04-systems/inference-time-routing.md#2-routing-pick-one-model-from-the-prompt-established) |
| **Capability (agent security)** | An unforgeable token or label attached to a value or tool call that records where it came from and what it may be used for; a runtime allows a sensitive call only if its arguments carry the right capability, so injected text cannot mint new authority | [Prompt injection](docs/05-alignment-safety-interpretability/prompt-injection-and-tool-use-security.md#5-defenses-around-the-model-isolation-by-design-active-research) |
| **Capacity factor** | In a mixture-of-experts layer, the multiple of the even-split token count that each expert can accept per batch; tokens beyond it are dropped or rerouted | [Mixture of experts](docs/02-deep-learning/mixture-of-experts.md#3-the-central-problem-keeping-the-experts-busy-established) |
| **Cascade (LLM)** | Serving pattern that runs models from cheap to expensive and stops when a quality signal accepts the answer | [Inference-time routing](docs/04-systems/inference-time-routing.md#3-cascading-try-cheap-escalate-on-doubt-established) |
| **Cascade routing** | Generalisation of routing and cascading that at each step may stop, continue, or jump to a different model | [Inference-time routing](docs/04-systems/inference-time-routing.md#4-cascade-routing-and-serving-the-cascade-active-research) |
| **Catastrophic forgetting** | Sharp loss of performance on earlier tasks when a network trained by gradient descent on shared weights is trained on new data. | [Page](docs/06-frontiers/continual-learning-and-catastrophic-forgetting.md#1-the-problem-and-why-it-was-surprising-established) |
| **Causal representation learning** | Learning latent variables from raw observations such that they are the causal variables of the system, so interventions and counterfactuals can be reasoned about | [Causal representation learning](docs/06-frontiers/causal-representation-learning.md) |
| **Centered hidden embedding similarity (CHES)** | Similarity of preferred and dispreferred response embeddings that predicts likelihood-displacement risk under DPO | [Beyond DPO](docs/03-modern-ai/preference-optimization-beyond-dpo.md#2-what-can-go-wrong-with-dpo-established-active-research) |
| **Chain of thought** | Prompting or training a model to write intermediate reasoning steps | [LLMs](docs/03-modern-ai/large-language-models.md#prompting-for-reasoning) |
| **Chain-of-thought faithfulness** | Whether a model's written reasoning reflects what actually caused its answer; measured by biasing prompts or planting hints and checking whether the reasoning admits them | [Reasoning models](docs/03-modern-ai/reasoning-models-and-test-time-compute.md#7-reading-the-reasoning-established-active-research) |
| **Chain-of-thought monitorability** | Whether a monitor reading a model's written reasoning can detect a behaviour of interest, such as reward hacking or sabotage; distinct from faithfulness, which asks whether the reasoning is the real cause of the answer | [CoT monitoring](docs/05-alignment-safety-interpretability/chain-of-thought-monitoring-and-steganography.md#1-why-the-reasoning-is-readable-at-all-established-active-research) |
| **Chain-of-thought necessity** | The condition that a model cannot complete a task without writing its intermediate steps (reasoning as computation rather than rationalization), which makes the steps harder to hide | [CoT monitoring](docs/05-alignment-safety-interpretability/chain-of-thought-monitoring-and-steganography.md#1-why-the-reasoning-is-readable-at-all-established-active-research) |
| **Chunkwise parallel form** | Computing a linear-attention or state-space layer as dense attention-like matrix products inside fixed-size chunks while carrying only the recurrent state between chunks | [Linear attention](docs/02-deep-learning/linear-attention.md#6-kernels-making-it-fast-on-real-hardware-established) |
| **Circuit complexity class** | A set of problems solvable by families of Boolean circuits with given gates, size and depth, such as $\mathsf{AC}^0$, $\mathsf{TC}^0$ and $\mathsf{NC}^1$; used to bound what one transformer forward pass can compute | [What transformers can compute](docs/06-frontiers/what-transformers-can-and-cannot-compute.md#1-the-vocabulary-of-complexity-established) |
| **Circuit efficiency** | How much output logit a circuit produces per unit of parameter norm; generalizing circuits are more efficient than memorizing ones above a critical dataset size, which is why weight decay eventually selects them | [Grokking](docs/02-deep-learning/grokking-and-delayed-generalization.md#2-the-puzzle-in-one-equation-established) |
| **Class-incremental learning** | Continual-learning setting where new classes arrive over time and the model must distinguish all classes seen so far without being told which task an input belongs to; the hardest of the three standard scenarios. | [Page](docs/06-frontiers/continual-learning-and-catastrophic-forgetting.md#the-three-scenarios) |
| **Closed-loop evaluation** | Grading a world model by the real outcomes of an agent whose actions depend on what the model shows it, rather than by the generated frames | [Video world models](docs/06-frontiers/evaluating-video-world-models-closed-loop.md#1-two-kinds-of-evaluation-established) |
| **Collusion signal** | A feature an untrusted policy plants in its attacks so that another copy of itself, acting as monitor, knows to call them clean; countered by honeypots and signal jamming | [AI control](docs/05-alignment-safety-interpretability/ai-control-protocols.md#32-untrusted-monitoring-and-collusion) |
| **Compounding error** | Growth of prediction error when a learned one-step model is fed its own predictions; bounded by $\varepsilon(L^k-1)/(L-1)$ for an $L$-Lipschitz model | [Model-based RL](docs/06-frontiers/model-based-rl-compounding-error.md#1-why-errors-compound-established) |
| **Conductance drift** | Slow change of a programmed device conductance after writing; in phase-change memory roughly a power law $G(t) \propto t^{-\nu}$ | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#4-why-the-answer-is-always-a-little-wrong-established) |
| **Conformal prediction** | Wrapping any model's predictions in intervals or sets that contain the truth with a chosen probability, using a held-out calibration set; valid when calibration and test data are exchangeable | [Distribution shift in emulators](docs/06-frontiers/distribution-shift-in-scientific-emulators.md#5-uncertainty-that-survives-shift-conformal-prediction-and-its-limits-established-active-research) |
| **Confused deputy** | A program that holds authority on behalf of one party and is tricked by another party into misusing it; an LLM agent acting with its user's privileges on attacker-written text is one | [Prompt injection](docs/05-alignment-safety-interpretability/prompt-injection-and-tool-use-security.md#1-why-this-is-not-a-jailbreak-established) |
| **Constrained decoding** | Restricting each next token to those that keep the output inside a regular expression or grammar, used to emit valid tool JSON rather than fluent-but-unparseable text | [Serving tool-augmented agents](docs/04-systems/serving-tool-augmented-agents.md#4-share-the-tool-schema-constrain-the-call-established--active-research) |
| **Continuous batching** | Serving policy that admits and retires sequences after every decode step (iteration-level scheduling) so variable-length outputs do not block each other | [Serving long-reasoning models](docs/04-systems/serving-long-reasoning-models.md#4-batching-long-variable-length-outputs-established-active-research) |
| **Continuous ranked probability score (CRPS)** | Proper scoring rule for a probabilistic forecast: expected distance between forecast samples and the outcome minus half the spread between samples; rewards calibrated, sharp ensembles over blurred averages | [AI for science](docs/03-modern-ai/ai-for-science.md#the-blurring-trap-why-low-error-is-not-a-good-forecast) |
| **Control evaluation** | A red-team exercise measuring a control protocol's safety (probability no attack succeeds) and usefulness against the best attack policy found | [AI control](docs/05-alignment-safety-interpretability/ai-control-protocols.md#2-the-control-game-established) |
| **Controllability (world model)** | How faithfully a world model's predictions follow the actions it is given; in closed loop it matters more for task success than visual quality | [Video world models](docs/06-frontiers/evaluating-video-world-models-closed-loop.md#5-why-closed-loop-changes-the-answer-established-mechanisms) |
| **Covariate shift** | A change in the distribution of inputs $p(x)$ between training and deployment while $p(y \mid x)$ stays the same | [Distribution shift in emulators](docs/06-frontiers/distribution-shift-in-scientific-emulators.md#1-three-kinds-of-shift-established) |
| **Coverage (repeated sampling)** | Fraction of problems solved by at least one of $k$ sampled attempts; it grows with $k$ and becomes accuracy only when a verifier can pick the right attempt | [Code generation](docs/03-modern-ai/code-generation-and-program-synthesis.md#4-sample-filter-select-established) |
| **Coverage (repeated sampling)** | The fraction of problems solved by at least one of $N$ samples; equals pass@$N$ when an exact checker is available | [Reasoning models](docs/03-modern-ai/reasoning-models-and-test-time-compute.md#5-spending-compute-at-test-time-established) |
| **Crossbar array** | Grid of row and column wires with a programmable device at each crossing; applying row voltages yields column currents equal to a matrix-vector product | [Memristive crossbars](docs/06-frontiers/memristive-crossbars-in-memory-computing.md#2-the-crossbar-ohm-multiplies-kirchhoff-adds-established) |
| **Cross-entropy** | Expected negative log-probability a model assigns to the true outcomes; the standard classification and language-model loss | [Probability](docs/00-foundations/probability-and-information.md) |
| **Data processing inequality** | If $X \to Y \to Z$ is a Markov chain then $I(X;Z) \le I(X;Y)$: processing cannot add information about the input | [Information theory](docs/00-foundations/information-theory-for-ml.md#4-mutual-information-and-why-it-is-hard-to-measure-established-active-research) |
| **Defer to trusted** | A control protocol that replaces an untrusted model's moderately suspicious outputs with a weaker trusted model's output instead of auditing them | [AI control](docs/05-alignment-safety-interpretability/ai-control-protocols.md#31-trusted-monitoring-defer-to-trusted-and-trusted-editing) |
| **Delta rule (fast weights)** | Memory write that stores only the correction $\beta(\mathbf{v} - W\mathbf{k})\mathbf{k}^\top$, one online gradient step on a key-to-value regression; the basis of DeltaNet | [Fast-weight programmers](docs/06-frontiers/fast-weight-programmers.md#3-the-delta-rule-memory-that-can-correct-itself-established) |
| **Dictionary learning** | Learning an overcomplete set of directions so that each input is a sparse combination of a few of them | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md#2-dictionary-learning-the-old-idea-established) |
| **Diffusion model** | Generative model that learns to reverse a gradual noising process | [Generative](docs/03-modern-ai/generative-models.md#diffusion-models) |
| **Double descent** | Test error falling, rising, then falling again as capacity grows past the interpolation threshold | [Learning theory](docs/00-foundations/learning-theory.md#double-descent) |
| **DPO** | Direct preference optimization: fit preferences with a classification-style loss instead of RL | [LLMs](docs/03-modern-ai/large-language-models.md#direct-preference-optimization-dpo) · [Beyond DPO](docs/03-modern-ai/preference-optimization-beyond-dpo.md) |
| **Draft model** | In speculative decoding, a cheap model, set of extra heads, or retrieval source that proposes tokens for the target model to verify; its quality affects speed, never the output distribution | [Speculative decoding](docs/04-systems/speculative-decoding.md#5-where-the-drafts-come-from-established-and-active-research) |
| **Dual LLM pattern** | Agent design in which a privileged model plans and calls tools but never reads untrusted content, while a quarantined model reads untrusted content but has no tools and returns only opaque variables | [Prompt injection](docs/05-alignment-safety-interpretability/prompt-injection-and-tool-use-security.md#5-defenses-around-the-model-isolation-by-design-active-research) |
| **Dynamical isometry** | Initialization under which all singular values of a deep network's input–output Jacobian are near one, so signals survive depth | [Normalization and μP](docs/02-deep-learning/normalization-initialization-mup.md#1-initialization-keeping-the-forward-pass-alive-established) |
| **Early exit (reasoning)** | Stopping a chain-of-thought during decode when a confidence, entropy or redundancy signal says further tokens are unlikely to help | [Serving long-reasoning models](docs/04-systems/serving-long-reasoning-models.md#3-early-exit-and-adaptive-stopping-active-research) |
| **Edge of chaos** | Boundary between ordered and chaotic dynamics where deep signal propagation is possible | [Dynamics](docs/06-frontiers/nonlinearity-and-dynamical-systems.md) |
| **Edge of stability** | Regime where the loss curvature hovers near $2/\eta$ during gradient descent | [Optimization](docs/00-foundations/optimization.md#second-order-ideas) |
| **Elastic weight consolidation (EWC)** | Continual-learning regularizer that penalizes moving each weight away from its old value in proportion to its Fisher information, from a Laplace approximation of the previous task's posterior. | [Page](docs/06-frontiers/continual-learning-and-catastrophic-forgetting.md#elastic-weight-consolidation-derived) |
| **Embedding** | A learned vector representing a token, image patch, or other item | [Linear algebra](docs/00-foundations/linear-algebra.md) |
| **Empirical Fisher** | Average outer product of per-example gradients at the observed labels; cheap, but generally not the Fisher and not a curvature estimate | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#3-the-empirical-fisher-trap-established) |
| **Empirical spectral density (ESD)** | Histogram of the eigenvalues of a layer's weight correlation matrix $W^\top W/N$ | [Heavy-tailed spectra](docs/06-frontiers/heavy-tailed-weight-spectra.md#1-the-random-baseline-marchenkopastur-established) |
| **Emulator (scientific ML)** | A learned model trained to reproduce a physical simulator's outputs far faster, such as an ML weather model trained on reanalysis | [AI for science](docs/03-modern-ai/ai-for-science.md#1-why-science-is-a-different-machine-learning-problem-established) |
| **Encoded reasoning** | Intermediate reasoning written in a form a human or monitor cannot read, such as a cipher or private substitutions, while still doing the work | [CoT monitoring](docs/05-alignment-safety-interpretability/chain-of-thought-monitoring-and-steganography.md#3-ways-the-window-closes-active-research) |
| **Energy per MAC** | Energy spent per multiply-accumulate; for optical hardware it may count only detected light, laser power, or the whole system, which differ by orders of magnitude | [Optical energy](docs/06-frontiers/optical-energy-and-nonlinearity.md) |
| **Entropy collapse** | The early, rapid drop in a policy's output entropy during RL fine-tuning, which narrows exploration and caps further gains | [Reasoning models](docs/03-modern-ai/reasoning-models-and-test-time-compute.md#3-what-happened-at-scale-established) |
| **Environmental injection** | Planting malicious content in the pages or apps an agent operates in, adapted to look native there, rather than sending it to the agent directly | [Multimodal prompt injection](docs/05-alignment-safety-interpretability/multimodal-prompt-injection-computer-use-agents.md#1-what-changes-when-the-agent-can-see-established) |
| **Equivariant neural network** | Network whose outputs rotate (or otherwise transform) exactly as its inputs do, building physical symmetries in rather than learning them | [AI for science](docs/03-modern-ai/ai-for-science.md#learned-interatomic-potentials) |
| **Ex-ante quality estimation** | Predicting, from the prompt alone and before any generation, whether a given model will answer well enough | [Inference-time routing](docs/04-systems/inference-time-routing.md#2-routing-pick-one-model-from-the-prompt-established) |
| **Expected improvement (EI)** | Acquisition function equal to the expected amount by which a point beats the best value so far; balances high mean against high uncertainty in closed form | [Gaussian processes & BO](docs/01-classical-ml/gaussian-processes-bayesian-optimization.md#3-bayesian-optimization-deciding-where-to-look-established) |
| **Experience replay (continual learning)** | Mixing a small stored buffer of earlier examples into training on new data so that old tasks keep being rehearsed. | [Page](docs/06-frontiers/continual-learning-and-catastrophic-forgetting.md#replay-and-the-surprisingly-strong-baseline) |
| **Fast weights** | A weight matrix rewritten during a forward pass, usually by outer products programmed by a slower trained network; causal linear attention is an example | [Fast-weight programmers](docs/06-frontiers/fast-weight-programmers.md#1-slow-weights-that-program-fast-weights-established) |
| **Feature absorption** | An SAE failure where a general feature silently stops firing on cases that a more specific feature has taken over, driven by the sparsity objective | [Sparse autoencoders](docs/05-alignment-safety-interpretability/sparse-autoencoders.md#7-the-reckoning-what-saes-do-not-give-you-active-research) |
| **Feature map (kernel)** | A function $\phi$ with $\kappa(\mathbf{q},\mathbf{k}) = \phi(\mathbf{q})^\top\phi(\mathbf{k})$; choosing one that factorizes the attention kernel is what makes attention linear | [Linear attention](docs/02-deep-learning/linear-attention.md#2-the-associativity-trick-established) |
| **Fill-in-the-middle (FIM)** | Training transformation that moves a middle span of a document to its end so a left-to-right model learns to complete code given what comes before and after the cursor | [Code generation](docs/03-modern-ai/code-generation-and-program-synthesis.md#3-code-as-language-established) |
| **Filler tokens** | Meaningless intermediate tokens (such as "......") that a transformer can still use for extra computation, showing that tokens can help without explaining anything | [CoT monitoring](docs/05-alignment-safety-interpretability/chain-of-thought-monitoring-and-steganography.md#1-why-the-reasoning-is-readable-at-all-established-active-research) |
| **Fisher information matrix** | Expected outer product of the score $\nabla_\theta \log p_\theta$; the second-order expansion of KL divergence and the metric of information geometry | [Information geometry](docs/00-foundations/information-geometry-natural-gradient.md#1-models-as-points-on-a-curved-space-established) |
| **FlashAttention** | An exact attention kernel that tiles the computation to stay in fast on-chip memory and, in the backward pass, rebuilds the attention matrix from the saved per-row log-sum-exp instead of storing it | [Attention gradients](docs/02-deep-learning/attention-gradients.md#5-the-identity-that-made-flashattention-possible-established) |
| **Fokker–Planck equation** | Partial differential equation for how the probability density of a diffusion evolves over time; used to study where SGD's parameters spend their time | [SGD as an SDE](docs/06-frontiers/sgd-as-a-stochastic-differential-equation.md#1-from-a-noisy-update-to-a-diffusion-established) |
| **Forecaster's dilemma** | Scoring forecasts only on cases where an extreme was observed rewards forecasters who always predict extremes; avoided by weighting the scoring rule rather than the test set | [Distribution shift in emulators](docs/06-frontiers/distribution-shift-in-scientific-emulators.md#4-scoring-under-shift-proper-scores-and-the-forecasters-dilemma-established) |
| **Foundation model** | Large model pretrained on broad data and adapted to many tasks | [Modern AI](docs/03-modern-ai/README.md) |
| **Fractal dimension** | Non-integer measure of how detail scales with resolution | [Fractals](docs/06-frontiers/fractal-and-self-similar-structure.md) |
